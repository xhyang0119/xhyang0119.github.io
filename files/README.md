# Public files only

Put PDFs (e.g. `cv.pdf`, `my-talk.pdf`) and your own portrait (e.g. `portrait.jpg`)
in this directory. Then set the matching relative path in `site.json` and run
`python3 build.py`.

Everything uploaded to this repository and website is intended to be public.
Do not upload private drafts, student records, passwords, or unpublished
materials that you are not authorised to share.
